# UFC Custom Ranking

Um projeto humorístico criado para simular a interface oficial de rankings do UFC, personalizado com piadas internas entre amigos. O aplicativo exibe integrantes do grupo como campeões de categorias de peso fictícias.

## Funcionalidades

- **Interface UFC Clone**: Visual fiel ao layout oficial de rankings do UFC, utilizando a identidade visual clássica da organização.
- **Categorias Customizadas**: Exibe categorias humorísticas de peso (ex: Peso-Deus, Peso-Gordim).
- **Cards Interativos**: Efeitos visuais de zoom e destaque ao passar o mouse sobre os cards dos campeões.
- **Atalho do WhatsApp**: Botão flutuante para contato direto com o grupo.

## Tecnologias Utilizadas

- **Framework**: React 18 (com TypeScript)
- **Estilização**: Tailwind CSS, Shadcn UI, componentes primitivos Radix UI
- **Ícones**: Lucide React
- **Build Tool**: Vite
- **Testes**: Vitest
